    \item \textbf{Prevención:} microambientes anóxicos
\end{itemize}
\end{exampleblock}

La saturación de poros por exceso de humedad es el principal detonante de anaerobiosis.

\begin{frame}{CO$_2$: Señal Fisiológica del Metabolismo Aerobio}
\begin{columns}[T]
\begin{column}{0.55\textwidth}
En condiciones óptimas, el proceso es \textbf{predominantemente aerobio}.
%\vspace{0.3cm}
\begin{block}{El CO$_2$ no es solo una emisión}
Es una \textit{señal fisiológica} de la intensidad metabólica:
\begin{itemize}
    \item Costos de mantenimiento
    \item Síntesis de biomasa estructural
    \item Acumulación de reservas lipídicas
\end{itemize}
\end{block}
\vspace{0.2cm}
\textbf{Flujo estable y creciente (primeros 10 días):}
\begin{itemize}
    \item Indica sistema metabólicamente activo
    \item Refleja asimilación neta del sustrato
    \item Base para el modelo bioenergético de Eriksen
\end{itemize}
\end{column}
\begin{column}{0.42\textwidth}
\begin{exampleblock}{Rango operativo seguro}
\begin{itemize}
    \item \textbf{Humedad:} 60--70\,\%
    \item \textbf{Temperatura:} 27--30$^\circ$C
    \item \textbf{Aireación:} suficiente
\end{itemize}
\end{exampleblock}
\vspace{0.2cm}
\begin{alertblock}{Lectura operativa}
Un flujo creciente de CO$_2$ valida que el reactor está en régimen aerobio deseado.
\end{alertblock}
\end{column}
\end{columns}
\end{frame}

% CH4
%======================================================================
\begin{frame}{CH$_4$: Metanogénesis en Microambientes Anóxicos}
\begin{alertblock}{Concepto clave}
El metano \textbf{NO} es producto directo del metabolismo larval. Es señal de \textbf{fallo operativo}: activación de arqueas metanogénicas en zonas anaerobias.
\end{alertblock}
\vspace{0.2cm}
\begin{columns}[T]
\begin{column}{0.48\textwidth}
\textbf{Rutas metabólicas:}
\begin{enumerate}
    \item \textbf{Acetoclástica:} acetato $\rightarrow$ CH$_4$ + CO$_2$
    \item \textbf{Hidrogenotrófica:} CO$_2$ como aceptor de electrones
\end{enumerate}
\vspace{0.2cm}
\textbf{Factores de formación:}
\begin{itemize}
    \item Exceso de humedad ($>$80\,\%)
    \item Compactación por alta densidad larval
    \item Sustrato muy fino (difusión lenta de O$_2$)
\end{itemize}
\end{column}
\begin{column}{0.48\textwidth}
\textbf{Rol de la bioturbación larvar:}
\begin{itemize}
    \item Fragmenta el residuo
    \item Modifica la estructura porosa
    \item Reduce tiempo en condiciones anóxicas
    \item \textcolor{rojoAlerta}{\textbf{Límite:}} densidad excesiva $\rightarrow$ compactación $\rightarrow$ anaerobiosis
\end{itemize}
\vspace{0.2cm}
\begin{exampleblock}{Potencial de calentamiento}
\textbf{PGC (100 años):} 27,2 veces el CO$_2$ (IPCC AR6)
\end{exampleblock}
\end{column}
\end{columns}
\end{frame}

\textbf{Condiciones de escape de N$_2$O:}
\begin{itemize}
    \item Limitación de sustrato (C orgánico)
    \item Variaciones bruscas de oxigenación
    \item Exceso de nitrógeno disponible

\end{itemize}

% COMPARACION
%======================================================================
\begin{frame}{Bioconversión vs. Compostaje Tradicional}
\begin{block}{Diferencia fundamental}
Escala temporal y arquitectura dinámica del material
\end{block}
\vspace{0.2cm}
\begin{columns}[T]
\begin{column}{0.48\textwidth}
\textbf{Compostaje tradicional:}
\begin{itemize}
    \item Pila estática o volteo periódico
    \item Núcleos anaerobios persistentes
    \item Mayor extensión espacial y duración
    \item Emisiones de CH$_4$ inherentemente más altas
\end{itemize}
\end{column}
\begin{column}{0.48\textwidth}
\textbf{Bioconversión con \BSF:}
\begin{itemize}
    \item Bioturbación continua (remoción orgánica)
    \item Microambientes anóxicos transitorios y menores
    \item Reducción del \textbf{60--80\,\%} de CH$_4$ vs. compostaje mal aireado
    \item Menor pérdida de N como N$_2$O (incorporación a biomasa)
\end{itemize}
\end{column}
\end{columns}
\vfill
\begin{alertblock}{Advertencia crítica}
La ventaja \textbf{NO} es inherente a la tecnología. Bajo malas condiciones (humedad $>$80\,\%, alta densidad, sustrato lignocelulósico recalcitrante), la bioconversión puede igualar o superar el perfil de emisiones del compostaje $\rightarrow$ \textbf{greenwashing involuntario}.
\end{alertblock}
\end{frame}

\begin{frame}{Cierre: La Variable Humedad como Determinante}
\begin{columns}[T]
\begin{column}{0.58\textwidth}
\begin{block}{Rango seguro: 60--70\,\%}
Mantiene la actividad metabólica en régimen aerobio donde las larvas operan con máxima eficiencia.
\end{block}
\vspace{0.2cm}
\begin{alertblock}{Riesgo por encima del 80\,\%}
Saturación de poros $\rightarrow$ difusión lenta de O$_2$ $\rightarrow$ anaerobiosis en horas $\rightarrow$ CH$_4$ + N$_2$O masivos.
\end{alertblock}
\vspace{0.2cm}
\begin{block}{Riesgo por debajo del 40\,\%}
Suspensión de actividad microbiana y larval: cero emisiones, pero también \textbf{cero bioconversión}.
\end{block}
\end{column}
\begin{column}{0.38\textwidth}
\textbf{Variables de segundo orden:}
\begin{itemize}
    \item Densidad larval
    \item Aireación forzada
    \item Composición proximal del sustrato (C/N, fibra)
\end{itemize}
